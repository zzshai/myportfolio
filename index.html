My Projects

1. Movie Playlist

The Movie Playlist is a website concept that allows users to browse and organize their favorite movies. It aims to make discovering and keeping track of movies easier and more convenient.

This project helped me practice creating an organized and user-friendly website.

2. Room Reservation System

The Room Reservation System is a proposed system designed to help students and teachers reserve available rooms more conveniently.

It aims to reduce paperwork, prevent scheduling conflicts, and make reservation requests easier to manage. Administrators can review and approve reservation requests through the system.

3. Baking Recipe Website

The Baking Recipe Website is a project inspired by my personal interest in baking. It provides an organized collection of recipes for different baked goods and pastries.

This project combines my creativity and interest in baking with my growing knowledge of web development.
